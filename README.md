# 🌸 Modest Wear – Dynamic E-Commerce Cards in React

A modern and elegant **Modest Wear E-Commerce Website** built with React. This project demonstrates dynamic product card rendering using reusable React components, showcasing a collection of stylish and graceful abayas with their images, descriptions, and prices.

The website features a soft pink and red color theme, a responsive navigation bar, product cards, and a structured footer to create a simple and attractive online shopping experience.

## ✨ Project Features

- 🌸 **Modest Fashion Collection:** Displays a collection of elegant abayas.
- 🛍️ **Dynamic Product Cards:** Products are rendered dynamically using JavaScript's `map()` method.
- 🧩 **Reusable Components:** Separate React components for Navbar, Cards, individual Card, and Footer.
- 🖼️ **Product Images:** Each product card displays its relevant image.
- 📝 **Product Descriptions:** Provides details about different abaya styles.
- 💰 **Product Pricing:** Displays individual product prices.
- 🏷️ **Discount Information:** Product data includes discount information.
- 📦 **Stock Information:** Product data includes availability status.
- 🧭 **Navigation Bar:** Includes Home, About, Products, and Contact links.
- 📱 **Responsive Layout:** Uses Bootstrap grid classes and responsive styling.
- 🎨 **Attractive UI:** Soft pink and red color combination with styled product cards.
- 🦶 **Organized Footer:** Includes quick links, collections, and contact information.
